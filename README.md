# Guitar Magic（Android 吉他调音器）

Kotlin + Jetpack Compose 编写的吉他调音器 + 节拍器，完全离线，音高识别算法（YIN）自行实现。
界面采用 iOS 风格设计（大标题、分组列表、iOS 开关/分段控件/滑块/步进器、底部标签栏）。

## 功能

**调音**
- 识别范围 55–1500 Hz，指针弹簧动画
- 拨弦触发式识别：检测到拨弦起音后，连续 3 帧高置信度、音高一致且落在琴弦音域内才显示；
  说话、滑音、敲击、背景声、噪声都不会触发；琴弦发声期间持续跟随，衰减后读数保留 1.5 秒
- 识别灵敏度（低/中/高）与识别模式（吉他琴弦 / 半音阶）可调
- 自适应环境噪声估计；50 Hz 四阶高通 + 2.2 kHz 低通滤波；中值 + 指数平滑让读数稳定
- 试听参考音、节拍器运行时自动暂停识别，避免把手机自己的声音当成琴声
- 显示音名（科学音高记号，可选升号/降号）、实际频率、音分偏差、标准音频率
- 内置标准 / Drop D / 降半音 / Open G / DADGAD
- **自定义调弦预设**：为每根弦选择任意音高（B1–C6），可新建、编辑、删除，本地保存
- 自动识别琴弦或手动锁定；长按琴弦试听参考音
- 切换预设时记住每根弦实际停在的音高，不会认错弦；吉他模式下按“正在调的那根弦”判断偏高/偏低
- **逐根引导调音**：从 6 弦开始，调准一根自动跳到下一根
- 调准精度可选（±2 / ±5 / ±10 音分）
- 已调准的弦打勾，6 根全部调准时庆祝动画；调准时提示音（可关闭）与振动反馈
- 基准音 A4 可在 430–450 Hz 之间调节

**节拍器**
- 30–250 BPM，按采样精确排布，长时间运行不漂移
- 每小节 1–12 拍、细分（八分 / 三连音 / 十六分）、第一拍重音
- 敲击测速（TAP）、意大利速度术语
- 摆锤与拍点动画与声音同步
- 速度训练：每 N 小节自动加速，直到目标速度
- 常用速度收藏、闪屏提示、振动提示

**界面**
- 支持横屏与平板（双栏布局）

## 代码结构

- `pitch/` 纯 Kotlin 的音高检测（YIN）、平滑、乐理计算
- `core/` 自定义调弦存储、调准进度、参考音合成
- `metronome/` 节拍器调度（纯 Kotlin）与 AudioTrack 播放引擎
- `audio/`、`tone/` 麦克风采集、参考音播放
- `ui/` Compose 界面
- `app/src/test/` 单元测试（算法 ±1 音分、节拍器零漂移等）+ Robolectric 界面冒烟测试
